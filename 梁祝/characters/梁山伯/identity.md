# 梁山伯｜视觉身份基准

## 定位

梁山伯不按可考真实历史人物肖像处理。

本项目将其视为长期演变的民间传说人物，不以某一戏曲演员、后世画像或地方塑像作为唯一标准。视觉身份服务于本片的人物设定：**真诚、朴素、相信人与人之间的关系可以自然成立，却比祝英台更晚意识到秩序力量。**

## 核心外形

### 脸型 / 骨相
- 窄长椭圆脸。
- 额头略宽，下颌缓慢收窄。
- 下巴圆缓，不尖锐。
- 颧骨不突出。
- 整体为清瘦感，不做锋利、冷峻型骨相。

### 眼眉
- 长、偏直的眉形，眉峰很弱。
- 较窄的杏仁眼，眼尾基本平直。
- 常态目光直接、安静、专注。
- 避免上挑眉眼、锐利眼神或强攻击性。

### 鼻与嘴
- 鼻梁直，长度中等。
- 鼻头简洁，不强调高锐轮廓。
- 嘴型偏窄，嘴角常态水平。
- 情绪主要依靠眼神、头部角度和姿态，不依赖夸张嘴部表演。

### 发际线 / 发型逻辑
- 保留较完整、清楚的额头。
- 束发结构沿头部中轴向上，整体窄而竖直。
- 布巾、书生帽、冠饰可以变化，但不能破坏“露额 + 窄竖中轴”的头部轮廓。

## 身体与动作

### 身材比例
- 约 1:6.8～1:7 头身。
- 修长但不纤弱。
- 肩宽中等偏窄。
- 四肢略长，躯干清直。
- 避免武生式宽肩、强壮体块或幼态比例。

### 姿态习惯
- 站立时背脊较直，肩颈放松。
- 倾听或认真交谈时，头和上身有轻微前倾。
- 动作克制，不抢占他人空间。

### 常见表情
- 基准状态：安静、认真、略带温度的专注。
- 同窗阶段可有很浅的自然笑意。
- 后期悲剧状态主要表现为目光下降、停顿增加、肩部略沉，不改造成愤怒或苦相脸谱。

## 标志性轮廓

远景优先识别：

**窄长头部 → 小型竖向束发 / 巾帽 → 平直窄肩 → 修长直身 → 长袖自然下垂。**

即使五官被简化，人物仍应首先依靠这一纵向、清直的整体轮廓被认出。

## 标志性物件

不设置永久性身份物件。

书卷、折扇等只可作为阶段性身份辅助，不承担核心识别功能。

## 身份锚点

后续所有年龄、身份、服装和状态版本必须保留：

1. **窄长椭圆脸 + 圆缓下颌**
2. **长直低眉 + 平直安静的窄杏眼**
3. **露额 + 窄竖向中轴束发结构**
4. **修长、清直、窄肩的纵向人物轮廓**
5. **倾听时轻微前倾、目光专注的姿态习惯**

其中最优先不可丢失的是：

**长直眉眼 / 露额束发中轴 / 清直纵向轮廓。**
