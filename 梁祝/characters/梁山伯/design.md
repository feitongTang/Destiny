# 梁山伯｜完整角色版本设计

## 总体原则

梁山伯只保留 **2 个必要视觉版本**：

- **V1｜自由同窗期**
- **V2｜认爱受阻期**

不单独建立病中 / 临终版本。后段应通过状态递减与人物从画面中的突然缺席完成断裂，而不是把梁山伯设计成第三种人物形象。

角色整体遵循本片的图形化 2D 人物体系：自然修长、轮廓优先、五官简化、服装以结构和大色块为主，避免高精度写实细节。

---

## 全版本身份锚点

以下元素任何版本都不能丢失：

1. **窄长椭圆脸 + 圆缓下颌**
2. **长直低眉 + 平直安静的窄杏眼**
3. **露额 + 窄竖向中轴束发结构**
4. **修长、清直、窄肩的纵向人物轮廓**
5. **倾听时轻微前倾、目光专注的姿态习惯**

最优先识别点：

> **长直眉眼 / 露额束发中轴 / 清直纵向轮廓**

---

# V1｜自由同窗期

### 对应剧情阶段
书院、山路、庭院、水边；与祝英台以同窗和知己身份平等相处的阶段。

### 大致年龄
青年，约二十岁上下。  
年龄不是版本划分依据，只保持年轻书生状态。

### 身材 / 身体状态
- 约 1:6.8～1:7 头身。
- 修长但不纤弱。
- 肩宽中等偏窄，四肢略长。
- 背脊清直，肩颈自然放松。
- 身体状态轻、稳定，没有明显疲态。

### 面部变化
基准脸。

- 窄长椭圆脸。
- 额头略宽，下颌圆缓收窄。
- 长直低眉。
- 窄杏眼，目光直接、安静。
- 嘴角常态水平，可有很浅的自然笑意。
- 不做俊美锐利型，也不做幼态书生脸。

### 发型变化
- 清楚露额。
- 束发沿头部中轴向上，窄而竖直。
- 可配简洁布巾或书生巾。
- 轮廓轻、整齐，不强调华贵冠饰。

### 服装
- 简洁书生常服。
- 交领 / 直领逻辑清楚，以宽袖、长衣摆形成纵向轮廓。
- 层次控制在 2～3 层。
- 面料偏朴素，无高密度纹样。
- 袖口、领缘可有极少量结构色差，不做繁复刺绣。

### 配饰
- 可阶段性使用书卷。
- 折扇可出现，但不作为固定标志。
- 不设置永久身份物件。

### 身份象征
**普通年轻书生 / 同窗。**

身份感来自：
- 简朴服装
- 书卷
- 清直姿态
- 与祝英台并肩而非前后主从的构图关系

不强调社会地位。

### 姿态
- 站立时背直、肩松。
- 与祝英台交谈时自然并肩。
- 倾听时头和上身轻微前倾。
- 行走步幅平稳，不抢占空间。
- 开放场景中身体可较自然地转向环境与对方。

### 常见表情
- 安静
- 认真
- 专注
- 很浅的自然笑意
- 对祝英台的关注首先表现为“知己感”，而不是明显恋爱凝视

### 主色倾向
- 月白
- 石青
- 浅青绿
- 暖米色

整体低到中饱和，人物与开放环境共享同一色域。

### 与上一版本最重要的视觉变化
无。  
这是梁山伯的视觉基准版本。

# V2｜认爱受阻期

### 对应剧情阶段
得知祝英台女性身份、意识到感情、来到祝家、确认彼此心意，却发现婚约和礼制程序已经启动；随后个人行动逐渐失效。

### 大致年龄
与 V1 基本相同。  
不通过显著年龄增长表现变化。

### 身材 / 身体状态
基础比例完全继承 V1，但状态逐渐收紧。

- 身体仍修长、清直。
- 肩部从放松变为轻微下沉。
- 胸腔和上身动作减少。
- 停顿增多。
- 后段可出现轻微疲惫，但不设计明确病容。

### 面部变化
骨相和五官比例不变，只改变状态：

- 眉眼仍保持长直和平静基底。
- 目光从直接、开放逐渐转为停留、下沉。
- 眼下可用极轻的色块压暗表现疲态，但不能写实化。
- 嘴角更少出现笑意。
- 不做愤怒、仇恨、哭丧式苦相。

核心是：

> **脸还是 V1 的脸，只是“相信事情还有办法”的神情逐渐消失。**

### 发型变化
- 继续保持露额 + 窄竖向中轴束发。
- 可比 V1 更整肃，布巾 / 冠饰结构稍正式。
- 不升级为华贵冠帽。
- 后段允许少量松动，但不能散发化或病态化。

### 服装
由轻松书生常服逐渐转向更正式、克制的外出 / 拜访服装。

- 结构比 V1 更整齐。
- 色块更沉。
- 青绿比例减少。
- 灰青、米白、暗木色增加。
- 袖、襟、腰部线条更收束。
- 仍保持朴素，不通过昂贵面料或复杂纹样制造身份升级。

### 配饰
- 书卷可减少或消失。
- 不增加新的高权力象征物。
- 如需外出身份辅助，只使用简洁巾帽、束带等。

### 身份象征
仍然是 **年轻书生 / 私人行动者**。

视觉重点不应变成“身份升级”，而是表现：

> 他仍以个人身份行动，但进入了一个由家庭、婚约和礼制控制的空间。

因此身份象征更多来自画面关系：
- 他站在门、屏风、桌案之外或之间
- 身体被框线切割
- 个人轮廓逐渐被礼制空间压缩

### 姿态
- 仍保留倾听时轻微前倾。
- 但从自然靠近逐渐变成克制地向前探。
- 肩部轻微下沉。
- 双手更常收在身体近侧。
- 与祝英台之间的距离被桌案、门框、帘幕等拉开。
- 后段动作减少，静止和停顿比 V1 明显增加。

### 常见表情
前段：
- 急切
- 认真
- 仍相信可以解决

中后段：
- 困惑
- 克制
- 目光停顿
- 失落
- 安静接受事实正在超出个人能力范围

避免把他处理成激烈反抗者或绝望疯癫者。

### 主色倾向
- 灰青
- 米白
- 暗木色
- 少量石青残留

朱红主要来自环境中的婚书、礼制物件和空间，不主动大面积进入梁山伯自身服装。

### 与上一版本最重要的视觉变化
最关键不是换装，而是：

> **从“身体自然处于开放空间”变成“身体仍清直，但被空间和自身状态逐渐压紧”。**

视觉变化集中在：
- 肩颈放松 → 肩部轻沉
- 目光直接 → 目光停顿 / 下沉
- 并肩关系 → 被框架分隔
- 青绿开放色域 → 灰青 / 暗木礼制色域
- 自然动作 → 动作减少、停顿增加

---

# 连续变化规则

V1 → V2 不应像换了一个角色，应采用渐变：

### 应逐渐变化
- **色彩**：石青 / 浅青绿逐渐减少，灰青 / 米白 / 暗木增加。
- **服装结构**：从较松弛的书生常服逐渐变得整肃、收束。
- **肩部状态**：放松 → 轻沉。
- **目光**：直接 → 停留 → 下沉。
- **动作频率**：自然移动 → 停顿增多 → 后段趋静。
- **空间关系**：开放并肩 → 门框 / 桌案 / 帘幕介入 → 可活动范围收窄。

### 不应突然替换
- 脸型与骨相
- 长直眉眼
- 露额束发中轴
- 修长窄肩比例
- 温和、克制的动作逻辑
- 朴素书生身份
- 基础服装轮廓

---

## 版本终点

梁山伯不建立 V3 病重 / 临终设计。

V2 后段只允许：
- 肩部更沉
- 目光更低
- 动作更少
- 服装稍显疲软

随后人物直接从画面中缺席。

下一次出现梁山伯，只保留墓碑上的名字。这样才能让“一个活生生的人突然被秩序结果抹去”的断裂成立。
