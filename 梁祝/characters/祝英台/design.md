# 祝英台｜角色版本设计

## 统一身份锚点

所有版本必须保留：

- 窄长鹅蛋脸，小而略方圆的下颌。
- 长杏眼，近直长眉，眉峰弱，眉尾略长。
- 干净额面，两鬓收束，头部轮廓纵向、利落。
- 长颈、窄肩、修长且挺直的身体轴线，约 1:6.7～1:7。
- 平视、克制、先观察后行动；受困时先“停止行动”，不做塌肩低头。
- 最高识别优先级：**眼眉关系 / 身体轴线 / 神态**。

人物整体遵循图形化 2D + 中强度 2.5D 体系：服装以结构、轮廓和大色块为主，五官与纹样简化，不做高精度刺绣、珠宝、发丝与写实皮肤细节。

---

## V1｜男装·自由求学期

- **对应剧情阶段**：换男装离家、书院求学、与梁山伯并肩相处的开放阶段。
- **大致年龄**：青年期；不以具体年龄形成版本差异。
- **身材 / 身体状态**：修长、轻快、有行动感；窄肩与长颈保持，步幅自然，身体轴线最舒展。
- **面部变化**：身份基准状态；面部最放松，眼神开放、直接。
- **发型变化**：男装束发，顶部轮廓简洁收束；额面与两鬓仍保持 identity 锚点，不用厚重额发改变脸型。
- **服装**：简洁书生男装，以直身、窄袖或适度宽袖、清晰衣襟和长下摆形成利落轮廓；不刻意男性化骨架。
- **配饰**：减量。可有束发件、书卷等阶段性物件；不设置永久个人饰品。
- **身份象征**：男装与书卷代表她暂时获得的“可自由行动、可平等进入公共世界”的身份。
- **姿态**：脊柱直，肩放松，头微抬；常与梁山伯平行站立或并肩行走，避免被动跟随姿态。
- **常见表情**：观察、清醒、淡微笑、专注交流；情绪主要靠视线与唇线变化。
- **主色倾向**：月白、石青、浅青绿、暖米色；低到中饱和，柔和对比。
- **与上一版本最重要的视觉变化**：首版，无上一版本。

## V2｜归家·女性身份恢复期

- **对应剧情阶段**：收到家书、回家卸下男装、恢复女性身份、婚约程序启动，到楼台会与梁山伯确认感情。
- **大致年龄**：与 V1 连续的同一青年期，不制造明显年龄跳变。
- **身材 / 身体状态**：骨架完全不变；行动幅度收小，停顿增多。身体仍直，但可活动空间与肢体展开程度明显下降。
- **面部变化**：脸型、眼眉不变；眼神由开放转为更早判断局势的克制与警觉。唇线更平，微笑减少。
- **发型变化**：由束发转为女性盘髻或收束髻式；仍保持干净额面、两鬓收束和纵向头部轮廓，避免繁复发髻改变识别。
- **服装**：女性常服，结构更规整、层次更完整，袖与裙摆可略增加垂坠感；纹样极少。服装从“行动方便”逐渐转向“合礼、被观看、被安排”。
- **配饰**：少量发簪或基础礼制配件即可；不可用华丽珠宝把角色贵族化。婚书、布料等属于场景 / 阶段叙事物件，不作为永久人物配饰。
- **身份象征**：盘髻、女性服装体系、门窗屏风与婚书共同表示她重新被纳入家庭与婚姻秩序。
- **姿态**：仍保持挺直和平视，但主动移动减少；常见状态是停在门框、桌案、屏风之间。受压时不是缩起身体，而是停止前进。
- **常见表情**：清醒、克制、提前知道局势已不可逆的沉静；面对梁山伯时可短暂出现柔和，但很快回到判断与克制。
- **主色倾向**：灰青、米白、木色、赭色增加；青绿减少；朱红开始以小面积进入。
- **与上一版本最重要的视觉变化**：**身份从“暂时获得公共行动权”切回“被家庭与婚约重新定义”**。变化重点不在女性化本身，而在轮廓、色域与姿态被逐步收紧。

## V3｜新娘·制度完成期

- **对应剧情阶段**：冷开场婚轿，以及结尾回到婚轿、在梁山伯墓前主动下轿的高潮阶段。
- **大致年龄**：仍与 V1、V2 连续，不做年龄型变化。
- **身材 / 身体状态**：基础比例不变；婚服增加视觉重量，步伐和转身受衣摆、袖量与轿内空间限制。下轿时恢复一次明确、主动、完整的迈步动作。
- **面部变化**：不做病态或憔悴化。眼神更沉、更定；情绪从“知道结果难改”推进到“结果已定后做最后一次主动决定”。
- **发型变化**：正式新娘盘髻 / 礼制头部结构，但必须控制大形，不以珠翠堆叠抢走身份锚点；额面与眼眉仍清晰可读。
- **服装**：完整婚服体系。朱红成为主体色，衣摆、长袖、层叠领口形成更重、更封闭的大轮廓；细节仍以大色块和结构为主，不做刺绣展示型设计。
- **配饰**：仅保留必要婚礼礼制配件与简化头饰。轿帘、婚服、婚轿是最重要的视觉共同体；蝶绝不作为她的私人饰品。
- **身份象征**：婚服与婚轿代表婚姻程序已经完成，她在现实社会中的身份已被正式确定。
- **姿态**：轿内动作极小，以抬眼、停顿、手部收束表现压迫；墓前最关键姿态是她**自己站起并走出轿门**，身体轴线重新明确打开。
- **常见表情**：安静、沉定、克制悲伤；避免持续哭喊式表演。高潮重点是行动决断，不是夸张面部情绪。
- **主色倾向**：朱红、暗褐、墨黑为主，冷暖对比明显；脸与轮廓保持高识别度。
- **与上一版本最重要的视觉变化**：**从“被安排中的女性”进入“婚姻程序已经完成的新娘”**。朱红由局部提示升级为大面积制度性色域，服装与轿框共同把人物空间压到最窄。

## 连续变化原则

以下元素应当逐步变化，而不是突然替换：

1. **空间中的身体展开度**：V1 最开放 → V2 停顿增加、动作变窄 → V3 轿内几乎静止；墓前下轿时短暂重新打开。
2. **色域**：月白 / 青绿 → 灰青 / 木色 / 少量朱红 → 大面积朱红 / 暗褐 / 墨黑。
3. **服装重量**：轻、便于行动 → 更规整、更具礼制感 → 最厚重、最具制度识别度的婚服。
4. **眼神**：开放观察 → 清醒判断 → 沉定决断。
5. **发型正式度**：简洁束发 → 收束盘髻 → 正式礼制盘髻；但额面、两鬓和纵向头部轮廓始终不变。

最重要的连续性：**经历让她越来越受限制，但不能把她设计成另一个人。V3 下轿时，观众仍应一眼认出 V1 那个主动走出家门的祝英台。**
