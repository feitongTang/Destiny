# 03 Visual Style｜梁山伯与祝英台

## 1. 核心视觉概念

整片采用**图形化人物 + 强分层景片 + 中强度 2.5D**的视觉体系。人物与场景都保持概括和平面化，不依赖高精度角色立绘，而通过前中后景关系、遮挡、Camera 穿层与空间收紧来推动叙事。核心视觉母题是“**框 / 蝶**”：人物逐渐被门、窗、屏风、婚书、轿帘等边界限制，蝶始终可以穿越这些边界。全片空间从开放走向封闭，最终在“无框天空”中彻底打开。

## 2. 2D 空间语言

整体偏向：**平面舞台 / 绘本景片 / 图形化拼贴 / 电影构图**，不追求完整三维真实感。

- **Background**：远山、天空、院墙、建筑大轮廓。低细节、弱透视，承担色域与空间尺度。
- **Midground**：主要叙事空间，如山路、书院、庭院、楼台、墓前。保持清晰大形，承载人物关系与主要动作。
- **Character**：位于中景核心层。人物不靠细节密度突出，而靠构图位置、轮廓、留白、光线和动作优先级突出。
- **Foreground**：门框、窗格、帘幕、屏风、枝叶、轿框、婚书等。大量用于遮挡、框取、压缩画面与制造 Parallax。
- **Atmosphere**：云、薄雾、尘、花瓣、水气、微光。只用于层间分离、深度和转场，不做重粒子特效。

空间原则：**每一层本身保持二维，层与层之间形成三维。**

## 3. 人物呈现

- **写实程度**：非写实，偏图形化动画人物；保留古代服饰逻辑，但不追求历史复原级细节。
- **比例**：自然修长，头身约 1:6.5～1:7；避免幼态大头比例，也避免写实人体建模感。
- **轮廓**：优先保证一眼可读。发型、长袖、衣摆、冠饰用大轮廓识别人物。
- **五官**：简化。眼、眉、鼻、口只保留必要信息；避免高精度瞳孔、睫毛、皮肤细节。
- **线条**：干净、稳定、适度粗细变化；人物线条清晰于背景，但不做繁复描边。
- **服装细节**：以结构、层次和大色块为主；纹样减量，只保留身份和时代感所需的局部纹样。
- **阴影**：以 1～2 层平涂阴影为主，少量局部软过渡；避免复杂体积光和厚重写实渲染。

人物设计必须服从整体画面：**角色不能因细节过高而从景片系统中“跳出来”。**

## 4. 场景

- **背景细节密度**：低到中。远景只保留轮廓、坡面、屋顶、树群等大形。
- **透视程度**：弱到中。允许必要的纵深和尺度差，但避免复杂广角透视、强消失点和真实三维建筑展示。
- **平面化程度**：高。建筑、山石、云、水均优先以轮廓和色块组织。
- **大形 / 剪影**：大量使用。尤其用于人群、礼制空间、建筑边界、婚轿和墓前环境。
- **前中后景关系**：必须明确。每个关键镜头至少有 2～3 个可独立运动的景片层；重要镜头优先用 Foreground 遮挡制造框取与深度。

空间递进：

1. **前期**：横向开放、远景可见、框较少。
2. **中期**：门、窗、屏风、桌案逐渐进入画面。
3. **后期**：画面被婚书、帘幕、轿框、门墙切割，人物可活动区域变窄。
4. **结尾**：逐层撤掉边界，最终只剩天空与蝶。

## 5. 材质

本项目只保留 4 类核心材质：

1. **绢 / 薄纸纹理**：用于背景大色面与天空，强度低；只提供轻微纤维感。
2. **剪纸 / 景片切边感**：用于前景、建筑轮廓、树石和群体剪影，强度中等；强调层与层的独立性。
3. **淡墨 / 水痕**：用于云、水、远山、雾气边缘，强度低到中；避免大面积写意泼墨。
4. **印泥 / 压痕质感**：只用于婚书、礼制文书、印章等“秩序”元素，强度中等，可作为视觉对比。

必须保持干净的区域：人物脸部、主要人物轮廓、关键构图留白、天空结尾。禁止全片统一叠加重纸纹、重颗粒或做旧滤镜。

## 6. 色彩｜Color Script

### 基础阶段｜自由 / 同窗
- 主色：月白、石青、浅青绿、暖米色
- 饱和度：低到中
- 对比：柔和
- 目标：空间开放、空气轻、人物与环境共享同一世界

### 情绪上升｜回家 / 身份恢复
- 青绿开始减少
- 木色、灰青、赭色增加
- 朱红首次进入，但面积有限
- 目标：从自然色域转向礼制色域

### 核心转折｜楼台会 / 婚约已成
- 主色：灰青、米白、暗木色、局部朱红
- 人物之间的空间对比加强
- 朱红不承担“邪恶”含义，而承担“程序已经启动”的视觉重量

### 高潮｜婚轿 / 墓前
- 朱红、暗褐、墨黑成为大面积主色
- 冷暖对比明显
- 环境可逐渐压暗，保留人物、帘幕和墓前风动的高识别度

### 结尾｜化蝶 / 无框天空
- 大幅减色
- 回到浅青、灰白、极淡暖光
- 降低饱和度与视觉噪音
- 目标：从“被颜色包围”转向“只剩空气和天空”

## 7. 光影

主要使用以下 5 种光影语言：

- **Flat Lighting**：常态。人物与场景保持平面可读性。
- **Large Shadow**：用于门内、轿内、屏风后、墓前等，形成大面积明暗切割。
- **Backlight**：用于人物离家、楼台会、墓前和结尾等关键节点，强化轮廓与空间边界。
- **Rim Light**：只在关键人物与深色背景重叠时使用，强度克制。
- **Haze**：用于远景、层间分离和空间打开，不做浓重体积雾。

避免复杂写实照明。光必须优先服务于**构图、边界、层级和情绪转折**。

## 8. 动态

### Camera
- 常态：缓推、缓拉、横移、纵深穿层、轻微俯仰。
- 禁止频繁自由旋转、手持抖动、强广角飞行镜头。
- 关键节点允许明显加强：穿门、穿帘、从窄框拉到开放空间、从多层框架拉到无框天空。

### Parallax
- 强度：中到较强。
- 关键镜头应明显可感知前 / 中 / 后景速度差。
- 前景遮挡物可以较快移动，中景人物较稳，背景最慢。

### Character Motion
- 强度：低到中。
- 以 Pose-to-Pose、转头、抬眼、抬手、迈步、停顿为主。
- 面部动画极少；情绪主要靠姿态、间距、朝向和构图表达。
- 高潮可加强一次明确动作：祝英台主动走出婚轿。

### Environment Motion
- 强度：中。
- 常用：衣袖、发梢、帘幕、云、水纹、树叶、尘、花瓣、蝶。
- 环境运动应比人物更持续，承担“画面一直活着”的功能。
- 墓前高潮可临时提高风、帘、衣袖、尘土的运动强度，随后迅速抽空。

## 9. 转场

主要使用 5 类：

1. **遮挡转场**：门框、帘幕、屏风、人物前景、轿帘扫过画面。
2. **Match Cut**：相同形状或构图关系匹配，如轿帘 → 家门、窗格 → 屏风、圆日 → 灯 / 月。
3. **景片穿层**：Camera 穿过前景层进入下一场景，保持 2.5D 连续性。
4. **光暗吞没**：强背光、暗部、黑色景片逐步占满画面，再进入下一场。
5. **材质变形 / 展开**：婚书、纸面、云、水、衣袖等图形元素扩展为下一场景的色块或轮廓。

避免依赖普通 Dissolve、随机粒子爆散、故障特效等与本项目空间语言无关的转场。

## 10. Avoid

以下问题会直接破坏本项目统一感：

- 主角画得明显比场景精细，形成“角色立绘 + 背景”的视觉割裂。
- 高精度瞳孔、发丝、皮肤、刺绣和珠宝细节抢走叙事注意力。
- 场景使用完整写实三维透视、复杂建筑建模或强广角镜头。
- Camera 长时间自由旋转、环绕人物、模拟游戏过场镜头。
- 所有景层都同速移动，导致 2.5D 只停留在技术分层而不可感知。
- 过量纹理、做旧、颗粒、墨迹覆盖人物和留白。
- 使用“发光神蝶”、强魔法粒子、超自然奇观提前定义蝶的意义。
- 朱红被简单处理成反派色或恐怖色；它应更像礼制与婚姻程序逐步占据空间。
- 群体角色全部高细节实名化，削弱“无人是唯一反派”的结构性表达。
- 转场依赖通用淡入淡出、闪白、Glitch，而不使用画面中的门、帘、光、景片和材质关系。
- 结尾继续保留复杂建筑、门窗、墙体或强烈视觉纹理，削弱“无框天空”的终点。

## 11. Image Generation Translation

### 核心视觉关键词
- graphic 2D characters
- simplified animated figures
- layered 2.5D stage space
- flat scenic cutout layers
- storybook staging
- graphic silhouettes
- restrained historical costume design
- frame motif
- butterfly crossing boundaries
- spatial compression and release

### 构图关键词
- foreground framing
- layered depth
- theatrical frontal composition
- strong negative space
- clear silhouette readability
- foreground occlusion
- parallax-ready composition
- horizontal scenic staging
- narrow framed composition
- open sky composition

### 材质关键词
- subtle silk texture
- light paper fiber
- clean cut-paper edges
- soft ink-wash atmosphere
- restrained seal-imprint texture
- clean matte surfaces

### 色彩关键词
- muted blue-green
- moon white
- warm rice paper beige
- gray cyan
- restrained vermilion accents
- dark brown and ink black in later scenes
- desaturated pale sky ending

### 光影关键词
- flat graphic lighting
- large shape shadows
- restrained backlight
- subtle rim light
- soft haze separation
- silhouette against light

### Negative / Avoid
- highly detailed anime face
- glossy 3D rendering
- photorealistic skin
- intricate embroidery overload
- dense jewelry detail
- realistic cinematic volumetric lighting
- complex perspective architecture
- dramatic fisheye lens
- full 3D game cutscene look
- excessive particles
- glowing magical butterfly
- heavy vintage filter
- dirty paper texture over everything
- painterly impasto
- random glitch transition aesthetic
- overly cute chibi proportions
- character poster composition
