# 《梁祝》视觉方案

> 状态：Confirmed
> 更新日期：2026-09-04

## 已选方向

**A｜纸影叙事**

**A2｜由暖入冷**

使用宣纸肌理、剪纸人物、皮影式侧身、局部朱红与有限的 2.5D 景深。书院阶段保留旧纸金、竹青和浅黛；告别之后逐层抽走色彩，只剩墨黑、灰白与婚礼朱红。化蝶时返还一点暖色，但不恢复完整春天。

## 视觉核心

人物像沿着纸上已有的折痕移动。没有人把他们推向悲剧，但窗棂、屏风、门框、婚书与礼仪不断将同一画面切开。结尾两只蝴蝶第一次脱离纸面边界，获得一种现实中不存在的自由。

## 基础色彩

| 功能 | 建议色 | 使用方式 |
|---|---|---|
| 旧纸金 | `#D8CAA6` | 书院阳光、记忆底色，不做明亮金色 |
| 竹青 | `#71806C` | 同窗阶段的生命感与空间层次 |
| 浅黛 | `#7D8B88` | 远山、雨、人物次级层 |
| 墨黑 | `#202522` | 人物剪影、制度性边界、后半段主体 |
| 灰白 | `#B9B7AA` | 病榻、纸钱、雨雾与被抽空的现实 |
| 婚礼朱红 | `#8C272C` | 束发红线、婚书、红绸与花轿；越到后半段越孤立 |
| 蝶翼余暖 | `#B65A45` | 只在最后蝶翼局部返回，不能铺满画面 |

## 人物设计

### 梁山伯

- 轮廓稳定、重心居中，纸片外形偏方正。
- 动作以停、回身、让路和迟一步的追随为主。
- 不用夸张木讷表情；通过视线方向与动作完成时间差表现“没有听懂”。

### 祝英台

- 男装与女装保留相同的核心轮廓，只改变发式、袖形和局部红线，避免换装奇观。
- 动作常有向门外、画面外或道路前方的微小倾向。
- 暗示不依靠口型或夸张表演，以停顿、袖口、递物和回望完成。

### 双人关系

- 同窗时尽量共享同一光区与地面线。
- 相送开始后，树影、门框和前景纸层逐渐插入两人之间。
- 相认时两人第一次正面面对彼此，却必须隔着屏风或门。
- 化蝶前不使用完全对称构图；双蝶出现后才获得短暂对称。

## 构图语法

- 门、窗、屏风和画框不是装饰，而是身份与礼法的可见边界。
- 重要镜头优先使用横向留白，让人物显得仍在同行或已经被分开。
- 婚书中的红线可以贯穿画面，逐渐变成道路、帘幕边缘或花轿系带。
- 不以巨大官府、恶人阴影等方式把制度具象成单一反派。
- 后半段画面层数逐渐减少，空间由书院的开放景深收缩为屏风后的扁平纸面。

## 核心意象回环

### 纸

书页 → 婚书 → 药方与纸钱 → 承载化蝶传说的画纸。

### 门

求学时打开 → 相送后关闭 → 相认时阻隔 → 墓前裂开。

### 红线

束发 → 婚约 → 红绸与花轿 → 蝶翼上一点残红。

### 双影

同行 → 错位 → 婚丧两路 → 双蝶远去。

## 段落视觉变化

1. **迎亲与孤坟**：冷灰雨幕中只有花轿明确的朱红，构图水平、仪式化。
2. **男装与相遇**：窗内扁平，门外第一次出现三层景深；束发红线极小。
3. **同窗四季**：旧纸金与竹青最完整，使用最丰富但仍克制的视差。
4. **十八相送**：道路保持连续，前景遮挡逐次增加，双人距离不变而画面边界变多。
5. **相认与婚约**：记忆以纸片翻页或构图匹配返回；婚书朱红成为画面最稳定的直线。
6. **婚丧并行**：红绸与白纸用形状和动作匹配剪辑，拒绝一边喜庆、一边煽情的简单对照。
7. **墓前与化蝶**：现实层逐渐退成纸面；蝶从画框外飞出，但镜头不追逐，只看它们变小。

## Limited Animation 规则

- 每镜头保留 1～3 个主要运动焦点。
- 人物以转身、停步、袖口、发带和视线为主要动作，不默认制作口型。
- Camera 运动优先于复杂肢体动作，但避免每镜都推近。
- 书院可使用轻微横移、前景竹叶与纸层视差；越接近结尾，Camera 越接近静止。
- 婚丧并行以构图匹配和动作匹配为主，不依赖特效转场。
- 化蝶只需要纸面脱离、轻微上下错相和景深变化，不做写实昆虫运动。

## 最低视觉基准

进入 Animatic 前只制作：

1. 一张“雨中红轿经过孤坟”的整体质感基准图。
2. 梁山伯稳定参考图一张。
3. 祝英台男装与女装共用的设计母版一张，并标出必要差异。
4. 一张“同窗四季”的暖色空间参考。
5. 一张“婚丧并行”的红白构图测试。
6. 一张“纸面化蝶”的结尾测试。

只有某个镜头确实需要独立运动时才继续拆层。原始素材不覆盖，正式入镜素材另存于 `assets/`。

## 文字视觉原则

- 文字应像影片中的一次戏曲表演，而不是说明字幕。
- 字体与纸面材质协调，但保证现代屏幕可读性。
- 每组唱词跨越多个镜头，不逐镜出现。
- 投坟高潮完全取消文字。
- 化蝶后的文字极少，避免与经典旋律同时争夺注意力。

## 禁止项

- 高饱和、通篇喜庆的民间剪纸装饰。
- 把祝父或马文才做成巨大阴影、黑脸或压迫性怪物。
- 所有纸层同速移动造成 PPT 感。
- 书院段落持续甜美滤镜，削弱身份隐患。
- 墓裂、闪电和化蝶的大型粒子奇观。
- 化蝶后恢复满画面春色或以灿烂光芒暗示圆满复生。
