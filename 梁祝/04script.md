# 风格

约3:00中国电影感叙事歌。单一清亮温润女声，第三人称。整体约80%越剧吟唱气质+20%现代国风流行；保持可听懂旋律，不做全程纯戏腔。清晰咬字，一字一音为主，句首自然，句尾用柔和滑音、倚音、回转和短拖腔；少用流行大线条旋律、强belt、密集转音、哭喊。段落间必须有呼吸、停顿和器乐答句，避免持续满唱。

独奏小提琴为情感主线，配清透竹笛/箫、克制室内弦乐、少量古琴点音、极轻低频打击。整体木质、古朴、电影感，避免EDM、trap、四拍流行鼓、煽情钢琴、预告片铜管、商业流行亮感、厚重鼓墙、过度颤音。

0:00–0:06 Intro：纯器乐。竹笛/箫独奏原创江南五声音阶短句，自由速度，弱起，缓慢上行，中间一次柔和倚音/滑音，高处短暂停驻，再以长尾音回落；小提琴轻接同一动机的不完整版本。远处喜乐、脚步、轿铃若隐若现，表面喜庆、内里不安。

0:06–0:18 Verse1→Break1：克制、疏离、带预感。女声稀疏，轻拖句尾；小提琴只给碎片答句。“轿停”近念白，之后音乐瞬间抽空。

0:18–0:47 Verse2/Inst：情绪明显转亮，空间骤然打开，表现同窗时期的自由亲近。戏腔稍减、声音清朗；竹笛句间回应，轻弦乐+古琴点音；Inst短暂无人声。

0:47–1:07 Verse3：由开放迅速收紧。速度感放慢、音域降低、情绪封闭；小提琴主题缩短并中断，轻木质敲击与门声进入。

1:07–1:38 Verse4：全曲最细腻、越剧韵味最浓。先有终于明白的温热，再转成已太迟的克制失落；小提琴与人声稀疏问答，不加厚鼓，不做流行高潮。

1:38–2:00 Transition：私人情感转为冷硬礼制。印章、剪刀、针线、箱笼、关门声组成稀疏机械节奏；人声断句，压迫感逐渐增加。

2:00–2:34 Build Up→Break2：从压抑转向主动决断。低弦与节奏逐层增强但不史诗化；末端成为意志峰值，随后突然停顿。风声升起，“风起/红衣满山”近念白，音乐退开。

2:34–2:40 Interlude：纯器乐。Intro笛子原创动机以更开阔变奏重现，小提琴从下方回应，安静轻盈。

2:40–2:56 Outro：空间最大、最远。人声舒展但不高亢；小提琴与竹笛交替完成主题。不是胜利，而是离开人间秩序后的辽阔与淡然。

2:56–3:00 Post Chorus：无人声。竹笛/箫呼应Intro同一原创动机：音区更高、音与音更疏、停顿更长，先轻柔上行，在高处悬停，再以两三个疏朗音回落；小提琴给未完全解决长音，淡入空气声。
